# Java
- Linguagem orientada a objetos.
- O ponto de entrada do java é o psvm (public static void main).
- String no java é um objeto e imutável.
- Metodo em java so pode ser usado se a variavel for wrapper e nao um primitivo, ja que um wrapper é um objeto e objeto tem metodos.
- codigo do programador em arquivo .java -> compilacao (javac) que vem dentro da JDK -> arquivo bytecode .class -> leitura do arquivo por JVM 
-> interpreta e JIT (just-in-time) -> arquivo binario -> CPU executa -> programa roda
- Pool, memoria heap, baby zone, VIM, ssh, logs   
- modificadores de acesso: public,  private, protected, default
- {modificador} {retorno} {nome}{argumento/parametro}
- private int random(int n1)
